##Calculadora EcoTrip

Um simulador simples e interativo de impacto ambiental para viagens. Este projeto calcula de forma ilustrativa a pegada de carbono de um trajeto com base no meio de transporte escolhido.

#Funcionalidades
Interface moderna e responsiva.
Simulação de emissão de CO₂ (valores mockados para fins demonstrativos).
Suporte para diferentes meios de transporte: Avião, Carro, Ônibus e Trem.
Dicas ecológicas dinâmicas baseadas no transporte selecionado.

#Tecnologias Utilizadas
Este projeto foi construído utilizando apenas tecnologias web padrão (sem frameworks):
- HTML5 (Estrutura semântica)
- CSS3 (Estilização, variáveis, flexbox e animações)
- JavaScript (Vanilla) (Lógica de cálculo e manipulação do DOM)

#Como Executar
Como é um projeto estático e sem dependências externas, rodar é muito simples:

- Faça o clone deste repositório ou baixe os arquivos.
- Dê um duplo clique no arquivo index.html para abri-lo no seu navegador padrão.
- (Opcional) Utilize a extensão Live Server do VS Code para abrir o projeto com recarregamento automático.
